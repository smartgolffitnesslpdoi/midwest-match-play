# Midwest Match Play

Rank the golf courses you've played in Illinois, Indiana, Michigan, Ohio and Wisconsin through quick head-to-head picks, Beli style. Course lists come from the state leaderboards on top100golfcourses.com.

## How it works

- Pick the course you prefer in each match. Each new course is placed in your list in about 4–6 matches.
- "Haven't played" removes a course from your list; "Too close to call" places it right below its opponent.
- Undo, re-rank any course, or move a skipped course back in from the My ranking tab.
- Every visitor builds their own list. Progress saves in their browser, so it stays on that device.
- "Copy as text" exports a ranking to share.

## Hosting on GitHub Pages

1. Create a new public repository and upload `index.html` (and this README).
2. Go to Settings → Pages, choose "Deploy from a branch," pick `main` and `/ (root)`, and save.
3. After a minute the game is live at `https://<your-username>.github.io/<repo-name>/`.
